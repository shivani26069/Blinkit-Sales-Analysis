# 📊 Blinkit Sales Analysis Dashboard

An Excel-based dashboard analyzing Blinkit's sales performance, customer satisfaction, and product distribution across various outlet types and locations.

## 📁 Project Overview

This project provides a visual and data-driven overview of key business metrics, built entirely in Microsoft Excel. It highlights important KPIs such as:

- Total Sales
- Average Sales
- Number of Items Sold
- Average Customer Rating

## 📈 Visualizations Included

The dashboard includes interactive charts and visuals for:

- Total Sales by Fat Content (Donut Chart)
- Sales by Item Type (Bar Chart)
- Fat Content vs. Outlet Performance (Stacked Column)
- Sales by Outlet Establishment Age (Line Chart)
- Sales by Outlet Size (Donut/Pie Chart)
- Geographic Sales Distribution (Funnel Chart)
- KPI Summary by Outlet Type (Matrix Card)

## 🛠 Tools Used

- Microsoft Excel (Dashboard, Charts, Data Modeling)

## 🎯 Purpose

The aim is to uncover actionable insights and support strategic decision-making for product optimization, customer engagement, and distribution planning.
